Prodigy InfoTech – Data Science Task 3

Decision Tree Classifier

This project is completed as part of my Data Science Internship at Prodigy InfoTech.

📌 Task Objective

Build a Decision Tree Classifier to predict the target variable using a suitable dataset. The project demonstrates the complete machine learning workflow, including data preprocessing, model training, prediction, and evaluation.

📊 Project Workflow

1. Load and explore the dataset
2. Perform data preprocessing
3. Handle categorical variables
4. Split the dataset into training and testing sets
5. Build a Decision Tree Classification model
6. Train the model using the training data
7. Make predictions on the test data
8. Evaluate the model performance
9. Visualize the Decision Tree
10. Analyze and interpret the results

🛠️ Technologies Used

- Python
- Google Colab
- Pandas – Data manipulation and analysis
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical visualization
- Scikit-learn – Machine learning and model evaluation

🤖 Machine Learning Model

The project uses a Decision Tree Classifier from Scikit-learn.

The model learns decision rules from the training data and uses them to classify new observations into their respective target classes.

📈 Model Evaluation

The classifier is evaluated using:

- Accuracy Score
- Confusion Matrix
- Classification Report
- Precision
- Recall
- F1-Score

A visualization of the trained decision tree is also included to understand how the model makes classification decisions.
